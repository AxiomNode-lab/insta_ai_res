# Code of Conduct

## Our standards

We are committed to a respectful, harassment-free community. Examples of welcome behavior include constructive feedback, empathy, clear technical evidence, respect for privacy, and accepting responsibility for mistakes.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing private information, credential or customer-data disclosure, and using project channels to facilitate spam, platform abuse, or unauthorized access.

## Enforcement

Project maintainers may edit, remove, or reject contributions and interactions that violate these standards, and may temporarily or permanently restrict participation when necessary.

Report conduct concerns privately to the repository owner through the contact options on the [@imedkablavi GitHub profile](https://github.com/imedkablavi). Do not include unrelated customer data or credentials. Reports will be reviewed with confidentiality proportional to the available GitHub controls.

This policy applies in project spaces and when representing the project publicly.
