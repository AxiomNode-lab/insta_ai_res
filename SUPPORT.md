# Support

- Use the bug report form for reproducible defects with synthetic data.
- Use the feature request form for policy-compliant product ideas.
- Use GitHub private vulnerability reporting for security issues.

This community project does not provide an emergency response SLA. Production operators should follow [RUNBOOK.md](RUNBOOK.md), retain tested backups, and keep a rollback image available.

Never share access tokens, webhook payloads, customer messages, database exports, or Redis contents in support requests.
